# 🧮 Calculator Web Application

A simple and beginner-friendly Calculator Web Application built using **HTML, CSS, and JavaScript**.

## 📌 Project Description

This project is a basic calculator that performs common mathematical operations such as addition, subtraction, multiplication, and division.

The main purpose of this project is to understand the basics of HTML structure, CSS styling, JavaScript functions, DOM manipulation, and button events.

## 🚀 Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear/Delete functionality
- Calculator display
- Button hover effects
- Responsive and simple user interface

## 🛠️ Technologies Used

- **HTML** – Creates the structure of the calculator.
- **CSS** – Designs and styles the calculator.
- **JavaScript** – Handles calculator operations and button functionality.

## 📂 Project Structure

```
Calculator/
│
├── index.html

```

## ▶️ How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start using the calculator.
